# CLOSET.exe — edição com sete personagens

Jogo de moda, cartas de caos e análise combinatória. Esta edição mantém as duas personagens femininas originais e acrescenta Ana, Isadora, Lívia, Nicole e Sophia. As opções masculinas foram retiradas da seleção.

## Como abrir

1. Extraia o arquivo ZIP inteiro para uma pasta.
2. Abra `index.html` no navegador.
3. Mantenha a pasta `assets` junto dos arquivos do jogo.

Não é necessário instalar nada para jogar. O armário, as cartas, o cálculo, o ranking local e as instruções continuam disponíveis.

## Personagens

As cinco fotos estão incluídas no jogo e aparecem na seleção do provador. As roupas e acessórios femininos do armário podem ser usados com todas as personagens.

## Cartas para imprimir

Abra `CARTAS-DE-CAOS.html` para imprimir as cartas. Durante a partida, escolha “Tenho uma carta física” e aplique o efeito da carta.
